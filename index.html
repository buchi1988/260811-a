01 / SELF-INFORMATION

珍しいほど、
情報は大きい。

毎日起こることより、めったに起きないことを知ったときのほうが驚きは大きい。その直感を対数で表します。

Definition

I(x) = −log2 P(x)

事象 x の確率 P(x) が小さいほど、得られる情報量 I(x) は大きくなります。底を2にすることで、単位は bit になります。

How surprising?

必ず起こるP = 10 bit
コインの表P = 1/21 bit
サイコロの1P = 1/62.585 bit
1%の出来事P = 1/1006.644 bit
i

bit は「0か1か」だけではなく、不確実性がどれだけ減ったかを測る単位でもあります。

02 / ENTROPY

平均すると、
どれくらい驚く？

起こりうるすべての結果について、情報量を確率で重みづけした平均。それがエントロピーです。

Expected surprise

H(X) = −Σ P(x) log2 P(x)

H(X) は情報源 X がもつ平均的な不確実性。公平なコインなら 1 bit、必ず同じ面が出るコインなら 0 bit です。

03 / SOURCE CODING

よく出るものを、
短く書く。

確率の高い記号に短い符号を割り当てれば、平均のデータ量を減らせます。これが可逆圧縮の核です。

A perfect-fit prefix code

AP = 1/20
BP = 1/410
CP = 1/8110
DP = 1/8111

Average code length

1.75 bit / symbol

すべてを2 bitで表す固定長符号より、平均 12.5% 小さくなります。

L = 1/2×1 + 1/4×2 + 1/8×3 + 1/8×3
H(X) = 1.75 bit → 理論限界に一致

Shannon's source coding theorem

H(X) ≤ L < H(X) + 1

十分長いデータをまとめて符号化すれば、平均符号長 L をエントロピー H(X) にいくらでも近づけられます。ただし、情報を失わずに H(X) より小さくすることはできません。

04 / NOISY CHANNEL

ノイズがあっても、
正しく送れる。

誤りが起きる通信路でも、冗長性を賢く加えれば信頼できる通信は可能です。その速度には上限があります。

Channel capacity

C = 1 − H2(p)

二元対称通信路では、反転確率 p が 0% なら 1 bit/use。50% では受信結果が完全にランダムになり、容量は 0 です。

05 / MUTUAL INFORMATION

知ることで、
何が減る？

ある変数を知ることで、別の変数の不確実性がどれだけ減るか。相互情報量は2つの変数が共有する情報を測ります。

Shared information

I(X;Y) = H(X) − H(X|Y)

Y を知る前の不確実性 H(X) から、知った後に残る不確実性 H(X|Y) を引いた量です。独立なら 0、完全に対応するなら H(X) と同じになります。

The whole idea in three steps

情報理論が教えてくれること。

01

驚きは測れる

珍しい出来事ほど大きな情報をもち、平均的な驚きがエントロピーになります。

02

圧縮には限界がある

情報源のエントロピーが、情報を失わない圧縮率の理論的な下限を決めます。

03

ノイズは克服できる

通信路容量より低い速度なら、符号化によって誤りを限りなく小さくできます。
