# 情報理論入門

「不確実さを、測る。」をテーマに、情報理論の基礎をインタラクティブに解説する日本語のWebページです。

## 内容

- 自己情報量と bit の意味
- エントロピーと二値エントロピー関数
- 情報源符号化とデータ圧縮の限界
- ノイズのある通信路と通信路容量
- 相互情報量とその応用

コインの表が出る確率や通信路のビット反転確率をスライダーで変更し、エントロピーと通信路容量の変化を確認できます。

## ローカルで表示

```bash
npm install
npm run dev
```

本番用ファイルは `npm run build` で `dist/` に生成されます。
